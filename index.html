Capabilities

Operational primitives for inspecting RF and signal artifacts.

Multi-trace
Load and overlay multiple measurement files for direct comparison.
Markers
Place markers, search peaks and minima, and create delta markers between points.
Trace Ops
Derive traces with offset, scale, smoothing, and A/B trace math.
Multi-pane
Compare traces in stacked panes with shared X navigation and independent Y scaling.
RF Analysis
Noise PSD, IP3, peak tables, range statistics, threshold crossings, bandwidth helpers.
No Online Deps
All libraries vendored locally. Works with direct file-open and GitHub Pages, no CDN runtime calls.

Supported Formats

Artifact intake. Frequency-domain output for every input format.

Format Notes
R&S .dat Rohde & Schwarz spectrum analyzer exports — primary tested target.
Amplitude-only .dat Frequency axis reconstructed from Start/Stop metadata.
.csv / .txt Generic delimited measurement tables.
Touchstone .s1p / .s2p / .sNp S/Y/Z matrix views, port-pair selection, and stability analysis.
.mp3 / .wav Decoded via Web Audio API; rendered as Hann-windowed averaged FFT (dBFS vs Hz).

Why I Built This

Field notes from an RF and broadcast engineer.

I’m a broadcast engineer—not a web developer. I needed a fast, practical way to inspect spectrum data, audio, and waveform captures directly in the browser without installing or maintaining heavy desktop tools. Nothing out there felt lightweight, flexible, and usable in real-world workflows, so I built this.

What started as a simple viewer for spectrum analyzer exports has evolved into a browser-based RF and signal analysis tool—capable of handling spectrum data and audio analysis in a unified interface.

Currently supported formats include:

  • Rohde & Schwarz .dat spectrum analyzer exports
  • Audio files such as .wav and .mp3, analyzed via FFT

The long-term goal is bigger:

a zero-install, browser-native signal analysis environment that supports real-time data, multiple instrument formats, and integration with modern SDR and monitoring systems.

If you find bugs, have ideas, or want to contribute, open an issue—this is being built for engineers who actually use this stuff in the field.
